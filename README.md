# AI Ad Campaign Generator

A lightweight front-end advertising tool that generates campaign strategy, budget allocation, and ad copy variants from user inputs.

## Features
- Campaign input form (product, objective, audience, budget, tone, channels)
- Automatic strategy recommendations by campaign objective
- Monthly budget split by selected channels
- AI-style ad copy variants with headlines, body text, and CTAs
- 7-day launch plan to operationalize the campaign

## Run locally
Open `index.html` in your browser.

## Deploy publicly on GitHub Pages
1. Create a new public repository on GitHub.
2. Push this project to the repository.
3. In GitHub repo settings, enable **Pages** and set the source to the main branch root.
4. Your public app will be available at:
   - `https://<your-username>.github.io/<repo-name>/`
